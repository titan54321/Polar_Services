# Polar

Landing page para Polar, técnico instalador de aires acondicionados.

## Publicación

Cada `push` a `main` publica el sitio en GitHub Pages con el workflow `.github/workflows/pages.yml`.
Solo se publican `index.html`, `styles.css`, `script.js` y `assets/`.

Sitio: https://titan54321.github.io/Polar_Services/

## Ver en local

```bash
python3 -m http.server 5173
```

Abre http://localhost:5173

## Pendientes del dueño

- **Logo:** reemplazar el `<svg>` del emblema en la barra de `index.html` (está marcado con un comentario).
- **Dirección y mapa:** reemplazar "Dirección por confirmar" en la sección de contacto (está marcado con un comentario).
- **Fotos:** las de `assets/img/` son de apoyo; cambiarlas por fotos reales de los trabajos.
