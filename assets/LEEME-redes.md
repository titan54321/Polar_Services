# Redes sociales

Pon tus enlaces en `redes.json`. Las redes sin enlace no se muestran; si ninguna tiene enlace,
la sección "Síguenos" no aparece en el sitio publicado. Redes posibles: facebook, instagram, tiktok, youtube.

```json
{
  "redes": [
    { "red": "facebook", "usuario": "Polar Aire Acondicionado", "url": "https://www.facebook.com/tu-pagina" },
    { "red": "instagram", "usuario": "@polar.aire", "url": "https://www.instagram.com/polar.aire" },
    { "red": "tiktok", "usuario": "@polar.aire", "url": "https://www.tiktok.com/@polar.aire" }
  ]
}
```
