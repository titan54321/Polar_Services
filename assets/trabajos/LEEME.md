# Fotos de trabajos realizados

1. Copia tus fotos a esta carpeta (de preferencia verticales, 4:5, de unos 1200 × 1500 px).
2. Agrégalas a `fotos.json`, una por línea, con el nombre del archivo y lo que muestra:

```json
{
  "fotos": [
    { "archivo": "minisplit-recamara.jpg", "texto": "Minisplit en recámara" },
    { "archivo": "local-centro.jpg", "texto": "Instalación en un local del centro" }
  ]
}
```

Mientras la lista esté vacía, la sección "Trabajos realizados" no aparece en el sitio publicado.
En tu computadora (localhost) se ven ocho espacios de ejemplo para revisar el diseño.
